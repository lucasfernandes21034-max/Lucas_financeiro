# Lucas Financeiro

Aplicação web de gestão da **LSF Soluções** (Santa Maria/RS): controle de clientes, projetos, horas, financeiro e indicadores de rentabilidade para um consultor solo optante pelo Simples Nacional.

## Documentos

- `PROMPT.md` — prompt de especificação do app, ponto de partida para o desenvolvimento.
- `SPEC.md` — especificação: modelo de dados, regras de negócio e fórmulas dos indicadores.
- `PLANO.md` — plano de marcos. A criar.

## Stack prevista

Python + FastAPI, React + TypeScript, PostgreSQL, Docker Compose, deploy via Coolify.
